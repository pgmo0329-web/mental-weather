# ⛅ SW학부 멘탈 기상청

충북대학교 소프트웨어학부 학생들의 오늘 컨디션을 **완전 익명**으로 모아 일기예보처럼 보여주는 웹서비스입니다.

- 배포 URL: https://mental-weather.vercel.app

## 주요 기능
| 화면 | 내용 |
|---|---|
| 오늘 예보 `/` | 학부 전체 날씨와 멘탈 지수, 학년별 날씨, 많이 나온 원인 태그, 캐스터 한마디, 다가오는 일정, 최신 현장 제보 |
| 내 날씨 `/vote` | 날씨 5단계, 학년, 원인 태그로 하루 1회 익명 제보 |
| 예보 달력 `/calendar` | 학년별/전체 공용 캘린더 (누구나 편집, 변경 기록과 되돌리기), 일정 기반 주간 예보 |
| 현장 제보 `/board` | 정보·질문·잡담·분실물 게시판, ☀️ 햇살(공감), 댓글 |

## 익명 보호
- 로그인이 없습니다. 투표에는 학년만 저장되고, 기기 구분은 브라우저 무작위 UUID의 SHA-256 해시로만 합니다.
- 개별 투표는 DB 보안 규칙(RLS)상 아무도 읽을 수 없고, 집계 함수만 결과를 돌려줍니다.
- 관측자가 **5명 미만**이면 전체·학년별 날씨를 공개하지 않습니다.

## 데이터 표시 범위
- **`샘플` 배지**가 붙은 일정·글·댓글은 `supabase/seed.sql`로 넣은 예시 데이터입니다.
- DB 연결 없이 실행하면 모든 화면이 브라우저 저장소의 예시 데이터로 동작하고, 메인 화면에 `예시 화면`이 표시됩니다.
- 캐스터 한마디는 AI가 아니라 집계 결과에 따른 **규칙 기반 문장**입니다 (`lib/caster.ts`).
- 정규 예보(08·12·18시)와 자동 특보는 아직 구현하지 않았습니다.

## 기술 스택
- 직접 구현: 화면, 집계 로직, 주간 예보 계산, SQL 스키마·보안 규칙·집계 함수
- 외부 기술: [Next.js 16](https://nextjs.org) (App Router), React 19, Tailwind CSS 4, [Supabase](https://supabase.com) (Postgres, Realtime), Vercel, 폰트 Do Hyeon (Google Fonts)

## 실행 방법
```bash
npm install
cp .env.example .env.local   # Supabase URL과 publishable key 입력 (없으면 예시 데이터 모드)
npm run dev
```
DB 준비는 [SUPABASE.md](SUPABASE.md)를 참고하세요.
