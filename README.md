# ⛅ SW학부 멘탈 기상청

충북대학교 소프트웨어학부 학생들의 오늘 컨디션을 **완전 익명**으로 모아 일기예보처럼 보여주는 웹서비스입니다.

- 배포 URL: https://mental-weather.vercel.app

## 주요 기능
| 화면 | 내용 |
|---|---|
| 오늘 예보 `/` | 학부 전체 날씨와 멘탈 지수, 학년별 날씨, 많이 나온 원인 태그, 캐스터 한마디, 다가오는 일정, 최신 현장 제보 |
| 내 날씨 `/vote` | 날씨 5단계, 학년, 원인 태그로 하루 1회 익명 제보 |
| 예보 달력 `/calendar` | 학년별/전체 공용 캘린더 (누구나 편집, 변경 기록과 되돌리기), 일정 기반 주간 예보 |
| 현장 제보 `/board` | 정보·질문·잡담·분실물 게시판, ☀️ 햇살(공감), 댓글. 익명 번호는 글마다 고정되고 글쓴이는 ✍️로 표시 |
| 관측 기록 `/records` | 학년별 멘탈 지수 추이, 일정이 날씨에 주는 영향, 많이 나온 원인, CSV 내려받기 |

## 익명 보호
- 로그인이 없습니다. 투표에는 학년만 저장되고, 기기 구분은 브라우저 무작위 UUID의 SHA-256 해시로만 합니다.
- 개별 투표는 DB 보안 규칙(RLS)상 아무도 읽을 수 없고, 집계 함수만 결과를 돌려줍니다.
- 관측자가 **5명 미만**이면 점수, 원인 태그, 학년별 인원을 공개하지 않습니다. 점수는 5점 단위로 반올림해서 한 사람의 투표를 역산하기 어렵게 했습니다.
- 게시판 익명 번호는 `해시(기기 ID + 글 ID)`로 정해서 같은 글 안에서만 같은 번호가 나옵니다. 서버에는 번호 문자열만 저장됩니다.

## 내일 날씨 예측
- 매일 00:05(한국 시간)에 전날 결과를 `daily_weather` 에 저장합니다 (Supabase `pg_cron`).
- 앞으로의 날씨는 DB 함수 `predict_day` 가 계산합니다.
  - **지금: 통계 방식.** 학년의 최근 4주 평균에, 지난 기록에서 구한 "그 일정이 있던 날의 평균 차이"와 요일 영향을 더합니다. 관측일이 적으면 기본 가중치(시험 −20, 과제 −10 …) 쪽으로 보정합니다.
  - **나중: 머신러닝.** 실제 관측일이 30일 이상 쌓이면 `ml/train.py` 로 학습한 Ridge 회귀 계수를 씁니다. 지금은 샘플 데이터로만 학습해 봤고, 검증 오차는 통계 방식 7.8점, Ridge 6.0점이었습니다. 자세한 내용은 [ml/README.md](ml/README.md)를 보세요.

## 악용 방지
- 모든 쓰기는 DB 함수로만 하고, 함수가 값 검사와 기기당 하루 횟수 제한(일정 20, 글 10, 댓글 50)을 합니다.
- 공감과 신고는 같은 기기에서 글·댓글 하나에 한 번씩만 됩니다. 게시 시각은 서버가 정합니다.
- 한계: 기기 ID는 브라우저에서 만들기 때문에 브라우저 데이터를 지우면 우회할 수 있습니다.

## 데이터 표시 범위
- **`샘플` 배지**가 붙은 일정·글·댓글·기록은 `ml/generate_sample.py` 로 만든 예시 데이터입니다 (`is_sample = true`). 사용자가 쓴 데이터는 샘플로 표시될 수 없습니다.
- DB 연결 없이 실행하면 모든 화면이 브라우저 저장소의 예시 데이터로 동작하고, 메인 화면에 `예시 화면`이 표시됩니다.
- 캐스터 한마디는 AI가 아니라 집계 결과에 따른 **규칙 기반 문장**입니다 (`lib/caster.ts`).
- 자동 특보는 아직 구현하지 않았습니다.

## 기술 스택
- 직접 구현: 화면, 집계 로직, 주간 예보 계산, SQL 스키마·보안 규칙·집계 함수
- 머신러닝: Python, scikit-learn (Ridge 회귀, 비교용 GradientBoosting)
- 외부 기술: [Next.js 16](https://nextjs.org) (App Router), React 19, Tailwind CSS 4, [Supabase](https://supabase.com) (Postgres, Realtime), Vercel, 폰트 Do Hyeon (Google Fonts)

## 실행 방법
```bash
npm install
cp .env.example .env.local   # Supabase URL과 publishable key 입력 (없으면 예시 데이터 모드)
npm run dev
```
DB 준비는 [SUPABASE.md](SUPABASE.md)를 참고하세요.
